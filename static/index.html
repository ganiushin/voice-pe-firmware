Прошивка Voice PE

Версия __VERSION__ · диалог без самопрослушивания

  1. Подключите Voice PE к компьютеру по USB-C.
  2. Откройте страницу в Chrome или Edge и нажмите «Установить».
  3. Если колонка уже была настроена, Wi-Fi и ключ API сохранятся. Новую колонку после прошивки настройте через Home Assistant.

Дальше колонка обновляется из Home Assistant. Исходники и описание: ganiushin/voice-pe-firmware. Вернуться на стоковую прошивку: установщик Voice PE.
